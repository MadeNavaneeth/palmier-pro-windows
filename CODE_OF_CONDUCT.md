# Code Of Conduct

## Our Pledge

We aim to make this project welcoming, focused, and respectful for contributors with different levels of experience.

## Expected Behavior

- Be respectful and constructive.
- Keep feedback specific and actionable.
- Assume good intent while still holding code, security, and claims to a high standard.
- Credit upstream work and contributors accurately.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks
- Sharing private information without permission
- Posting credentials, exploit details, or private media in public issues
- Misrepresenting this project as affiliated with Palmier, Inc.

## Enforcement

The maintainer may edit, hide, or remove comments and may block contributors who repeatedly violate this code of conduct.
